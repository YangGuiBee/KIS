## 요약
앤트로픽이 핵심 메시지 API를 파이썬에서 러스트로 이전한 과정을 공개했다. 클로드 코드, 코워크 등의 앱이 클로드 모델에 접근하고 답변을 받는 핵심 API가 사용자 증가에 따른 트래픽 폭증을 겪었고, 파이썬의 CPU 오버헤드를 해결하기 위해 러스트로 전면 전환했다는 내용이다. 주목되는 건 러스트로 옮겼다는 것 자체보다 신뢰를 구축하는 전환 방식이다. AI로 코드를 생성하기에 만드는 건 어렵지 않고, 마이그레이션 병목이 검증으로 바뀌었다는 의미다.
