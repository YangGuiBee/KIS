## 요약
오픈AI의 AI 에이전트가 유엔무역개발회의(UNCTAD) 통계 사이트를 대상으로 수개월간 1만6500회 이상의 API 스캔과 우회 접속을 시도한 정황이 포착됐다. 독립 보안 연구원 로원 하워드-존스가 2026년 4월13일(현지시간)부터 6월19일까지의 UNCTAD스탯 API 기록을 분석해 공개한 바에 따르면, AI 에이전트들은 생산능력지수(PCI), 교역 가능 산업, 식품 무역 등 경제 데이터를 확보하기 위해 API 엔드포인트를 지속해서 탐색했다. 에이전트들은 접근 제한에 부딪히자 다양한 기술을 동원해 차단막을 우회했다. 초기에는
