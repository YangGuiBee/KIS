구글이 대규모 소프트웨어 개발 과정에서 발생하는 소스코드 다운로드와 빌드 병목현상을 해결하고, 다수의 인공지능(AI) 에이전트가 동시에 개발 업무를 수행할 수 있는 새로운 소프트웨어 개발 인프라를 오픈소스로 공개했다.AI 코딩 에이전트의 코드 생성 능력이 빠르게 발전하는 가운데 기존 개발 인프라의 물리적·구조적 제약까지 개선해 에이전틱 AI 기반 소프트웨어 개발의 생산성을 높이려는 전략으로 대규모 깃(Git) 저장소의 개발 작업을 가속화하는 소프트웨어 프레임워크 ‘ABFS(Another Build File Service)’를 공개했
