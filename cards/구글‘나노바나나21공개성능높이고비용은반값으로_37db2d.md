## 요약
구글이 이미지 생성 모델 ‘나노 바나나’의 성능과 비용 효율을 동시에 끌어올렸다. 고해상도 이미지의 사실감과 편집 정확도를 높이고 여러 참조 이미지와 캐릭터를 일관되게 처리하면서도 생성 비용은 크게 낮췄다. 구글은 6일(현지시간) 이미지 생성·편집 모델 ‘나노 바나나 2.1(Nano Banana 2.1)’을 공개했다.‘제미나이 3.6 플래시’를 기반으로 개발된 이번 모델은 이전 버전보다 이미지 이해와 생성 품질을 높이는 동시에 이미지 생성 비용을 절반 수준으로 낮춘 것이 핵심이다. 1K, 2K, 4K 해상도에서 비주얼 품질과 사실감
