## 요약
메타가 복잡한 코딩과 여러 단계에 걸친 작업을 개인용 컴퓨터에서 수행하는 데 초점을 맞춘 오픈웨이트 모델 ‘뮤즈 스파크 오픈(Muse Spark Open)’을 공개했다. 8160억개의 매개변수를 갖춘 멀티모달 모델로, 애플과 협력해 맥 스튜디오 두 대를 연결한 환경에서 실행하도록 최적화했다.메타는 15일(현지시간) 뮤즈 스파크 오픈의 가중치를 공개하고 외부 플랫폼을 통한 API 서비스를 시작했다고 밝혔다. 회사는 이를 “현재까지 가장 뛰어난 미국 오픈웨이트 모델”이라고 소개했다. 개발자가 모델을 내려받아 자체 환경에서 실행하고 수정
