## 핵심 키포인트
- **80 에이전트 구조**: 오케스트레이터(팀장) + 실행 50(‘캐스팅’=팀빌더 스킬) + 리뷰 5(FAB Color: black필자/red비판/blue옹호/silver전문가/gold고객·상사) + 판단 어드바이저 25(철학자·전략가…이순신 포함). 7단계 워크플로우 중 **1번(목표)·7번(판단)은 사람 몫**.
- **AI 활용 6레벨(자율주행 차용)**: L3 바이브코딩(조건부 자동화) → **L4 하네스 엔지니어링**(멀티에이전트 오케스트레이션: 롤·평가기준·컨텍스트·도구·순서·**가드레일**) → **L5 루프 엔지니어링**(시작·중단 조건, human-in-the-loop).
- **컴퍼니 브레인** = 스킬 라이브러리 + MCP 커넥션 + 날리지 베이스(암묵지 자산화). 개인 AI활용을 조직 AX로 '증류'.
- **에이전트 리더십 ↔ 피플 리더십**: 피플=Why(동기부여), 에이전트=What(태스크 설계). 인사 6단계 중 피플은 '평가', 에이전트는 '**채용**'(안 되면 즉시 교체) 중심. 승진=자율성 부여 수준.
- **진짜 병목 = 3번(휴먼-에이전트 팀 = HR·조직문화)**. 저항감·두려움 관리가 리더의 핵심 변화관리. "**X톤**"(임원 해커톤 생중계) 제안.
- 리더가 먼저 써야(DBS "AI는 승인이 아니라 주도·함께"). HTML 슬라이드 보고(PPT 대체) = 변화의 시작점. 본인 스킬·슬라이드 라이브러리를 GitHub public 공개.

## 우리 업무 적용점
- **우리 AI팀 구조와 판박이** — 오케스트레이터+실행+리뷰+판단 = 루과장(총괄)+서브에이전트 병렬+전문가 자문. "겉 하나, 속 병렬" 모델 검증됨(`[[team-surface-model]]`).
- **컴퍼니 브레인 = 우리 표준·스킬/훅·근거자료집·auto-memory·KM 사이트** 그 자체 = 암묵지 자산화(`[[dev-standards-pmo-tool]]`).
- **하네스/루프·가드레일 = dev-standards-kit 훅(가드레일) + PMO 게이트**와 정확히 대응. "가드레일 정말 중요" = 우리 무-지어내기·시크릿차단 훅.
- **에이전트 리더십(채용·평가·자율성 프레임)** = (5) 전문가 AI 활용방안 구체화의 뼈대. 팀장님의 AI팀 운영방식 정립에 직접 적용.
- **HTML 슬라이드 보고** = 우리 리포트/젠스파크 PPT 방향과 일치.

## 핵심 슬라이드 (캡처 → 텍스트화 · `KM/80ai_26083/` 9장)
- **① AX Methodology 10박스** — 업무구조(What): 1 업무 역할 정의(핵심)·2 핵심 업무 목록·3 시간 배분 현황·4 업무 입출력 구조 / AI전환(Why): 5 AI 대체 가능성(좁은 의미 AX)·6 협업 구조·7 성과 기준 / AI관점: 8 AI 기술 매핑·9 **AI 가드레일**(책임자·보안·통제)·10 성장 방향.
- **② 리더의 3대 AX 고민** — Ⓐ Frontier Model(어떤 모델/내부 LLM) Ⓑ **Company Brain**(스킬 라이브러리→MCP 커넥션→날리지 베이스) Ⓒ **Human-Agent Team**(Human Harness + AI Harness = Meta Harness).
- **③ AI 활용 6레벨**(사람 제어→AI 실행): L0 기본채팅(수동) → L1 기본기(Projects·멀티페르소나) → L2 확장·연결(Chrome·Office·부분자동화) → L3 클로드코드(감독자·조건부) → L4 에이전트 설계(Skills·MCP·고도) → L5 루프 자동화(Routines·완전자동화).
- **④ 하네스 엔지니어링** — LLM 중심 6요소 링: **Role·Rubric(평가기준)·Context·Tools·Workflow·Guardrail**. "롤에서부터 시작".
- **⑤ 루프 엔지니어링** — 하네스 루프를 감싸는 **Trigger(시작)·Stop(중단)** 조건.
- **⑥ 50 에이전트 캐스팅**(팀빌더 스킬 UI·GitHub 공개) — 전략기획·마케팅·디자인·인사·재무·법무 등 50역할(예: 경영전략가·신규사업개발·사업타당성분석가·제품기획자).
- **⑦ AI와 함께 일하는 7단계**: 1 목표 `/goal`(완료기준 먼저) · 2 형식 `/slide-library`(16:9·A4) · 3 팀구성 `/casting`(×50) · 4 리뷰 `/5color`(×5: black필자·red비판·blue옹호·silver전문가·gold고객) · 5 윤문 `/korean` · 6 검증(팩트·출처·논리 병렬) · 7 판단 `/Council`(×25).
- **⑧ 라이너 스콜라** — 멀티에이전트가 논문 탐색·비교·인용·검토를 수행(피어리뷰 멀티페르소나 착안점).

> ★ ④⑤ 하네스/루프·가드레일 = 우리 dev-standards-kit 훅(가드레일)·PMO 게이트와 1:1. ③ 6레벨 = 우리 팀 성숙도 진단 축으로 차용 가능. ⑦ 7단계 = 우리 산출물 파이프라인(목표→형식→병렬생성→리뷰→검증→판단)과 동형.
