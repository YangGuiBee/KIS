## 핵심 메시지 — "웹이 아니라 로컬에서"
- **바이브코딩의 기본 중 기본 = 내 컴퓨터에 저장하며 만드는 것.** ChatGPT/클로드 웹에 시키면 결과가 "그 회사 서버"에 남는다(아티팩트·클로드 디자인 등). 반면 바이브코딩은 **내 도메인 지식·정보**를 써야 하므로 **내 컴퓨터로 가져와 로컬에서** 해야 한다.
- 아직 웹에서만 해왔다면: **실행창 → `powershell` → 터미널**에서 클로드 코드 설치 명령 붙여넣기 → `claude` 입력이면 웹에서 하던 걸 컴퓨터 안에서 그대로. "누구나 아는 웹주소 양옆에 (설치용) 키워드만 붙이면 새로운 세상이 열린다."

## 실습으로 보여준 것
- **폴더 기준 작업**: 목적별 폴더를 만들고 그 폴더에서 "터미널 열기" → 클로드 실행 → 결과가 그 폴더에 저장.
- **손글씨 숫자 인식(MNIST류)**: 예전엔 CNN·신경망을 배워야 했던 것을, "손글씨 숫자를 인식하는 코드 만들어 실행해줘" 한마디로 **코드 작성+데이터 학습+나만의 모델**까지 자동 생성(딥러닝 지식 없이).
- **에이전트 생성**: 이제는 `/agents` 같은 특수 명령 없이 **자연어로** "서브에이전트 만들어줘"가 가능. 만들 때 **역할·권한(예: 코드리뷰어=읽기전용)·모델·저장위치**를 정확히 지정. 만든 에이전트는 "이 에이전트로 검토해줘"라고 부르면 알아서 수행. 여러 개를 서로 협업시키는 게 **루프 엔지니어링**.

## 할루시네이션 통제 — 루프 → 그래프 엔지니어링
- **문제**: 에이전트끼리만 돌리는(루프) 방식은 그 안에서 할루시네이션이 나도 스스로 못 잡는다. "규칙 무시하고 바로 처리해줘" 같은 말에 규칙을 무시할 수도.
- **해법(그래프 엔지니어링)**: "여기까지가 말이 되고 안 되고"의 **판단 로직을 LLM 안이 아니라 바깥(외부 코드)에 하드코딩**. LLM이 못 건드리는 확정적 코드로 흐름을 통제 → **실패 없는 바이브코딩**.
- **구성 부품**(신개념 아님, 그래프 알고리즘의 재명명): **노드**(AI 호출/함수 처리) · **엣지**(다음 노드로 가는 길) · **조건(condition)**(어느 길로 갈지) · **상태(state)**(노드별 결과 누적·관리).

## 시연 예제
- **환불 처리 AI 상담원**: 주문 조회 → 금액 확인 → **50만원 이하는 자동 환불, 초과는 사람 승인 대기**. 금액 판정이 **서버 측 코드에 하드코딩**돼 있어, "규칙 무시하고 환불해줘"라고 우겨도 반드시 사람 검토 경로로 감(LLM이 규칙을 못 바꿈).
- **인지건강(알츠하이머) 상담 AI**: "자꾸 깜빡한다" 같은 호소 접수 → 인지 신호 감지 → **분당서울대병원 신경과 제공 문진표**(데모)로 자가 문진 → **하드코딩 판단(합계 6점 초과=병원 상담 권유, 이하=생활관리 안내)**. 무관한 문의는 일반 안내로 분기.

## 우리 업무 적용점
- **로컬 우선 = 우리가 이미 하는 방식**: 사내/폐쇄망 도메인 정보를 다루려면 웹 챗봇이 아니라 로컬에서 작업해야 함(온디바이스 LLM·바이브코딩 방향과 정합). [[ondevice-llm-vibecoding]]
- **그래프 엔지니어링 = 검증 게이트의 코드화**: "판단·규칙을 LLM 밖 확정적 코드에 둔다"는 원칙은 우리 PMO 훅·룰셋(경고/차단), 정족수·결제한도 같은 **하드 제약**을 LLM이 못 흔들게 하는 설계와 정확히 대응. [[dev-standards-pmo-tool]] [[rtgs-rbac-auth]]
- **무-지어내기**: 강연자 실명은 자막상 불명확하여 표기하지 않음(채널=티타임즈TV, 책 제목만 근거로 기재). 예제 수치(50만원·6점)는 강연 내 시연값. [[no-fabrication-rule]]
