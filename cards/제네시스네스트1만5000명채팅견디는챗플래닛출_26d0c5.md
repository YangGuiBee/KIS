## 요약
AI 소프트웨어 전문 제네시스네스트(대표 이동수)는 대규모 동시접속 환경에서도 실시간 메시지를 안정적으로 처리하는 채팅 솔루션 '챗플래닛(CHATPLANET)'을 개발하고 팬덤 플랫폼과 라이브 서비스 등 대규모 고부하 채팅 시장 공략에 나섰다고 4일 밝혔다.챗플래닛은 실시간 채팅 기능을 API 형태로 제공하는 기업용 솔루션이다. 1대1·그룹 대화는 물론 아티스트와 다수 팬이 함께하는 1대 N 대규모 채널까지 지원한다. 웹소켓·STOMP 기반 양방향 메시지 전송과 함께 푸시 알림, 금칙어 필터링, 사용자 차단·신고, 15개 언어 자동
