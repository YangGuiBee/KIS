## 핵심
- **무엇**: 한국 서비스용 **공개 API 모음(README 목록형)**. 한국 API **300+**, 글로벌 public API **780+**. 한국어/English/글로벌 3개 목록 제공.
- **품질 관리**: **Link Health Check**(GitHub Actions로 링크 유효성 자동 점검), MIT 라이선스, 주기적 업데이트(README "2026년 8월 13일 기준 최신"). 별 **2,980개**.
- **분류 예**: 공공데이터포털(data.go.kr) **활용신청 TOP10**(1위 기상청 단기예보 조회서비스 등), 기상·공공·금융 등 분야별 정리.

## 우리 업무 적용점
- **공공·금융 API 탐색 창구**: 데이터 수집·연계 과제 시 1차 참고(RTGS/ACS 등에서 외부 데이터·기관 연계 검토 시).
- **무-지어내기**: 실제 사용 전 각 API의 존재·스펙·이용조건은 **원 제공기관 공식 문서**로 재확인(모음집은 링크 인덱스). [[no-fabrication-rule]]
