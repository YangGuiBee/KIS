## 2. UI/기능 개선
- **카드 테두리**: 1px → 2px 굵게, 하늘색 `#7dd3fc`(펼침 시 `#38bdf8`).
- **펼침/접힘 삼각형(▾)**: 하늘색·22px·굵게(테두리색과 통일, 회전 애니메이션).
- **사이트 제목**: "AI 관련한 놓치면 안되는 정말 중요한 지식정보사이트(KIS)" → "놓치면 안되는 정말 중요한 AI 지식정보사이트(KIS)".
- **링크 일반화(향후 대비)**: 카드마다 유튜브·웹페이지를 선택 표시.
  - `video:` → 🔴 YouTube(실제 CI 로고 SVG, 라벨 "▶ 영상"→"YouTube")
  - `link:` → 🌐 WWW(지구본 아이콘)
  - 둘 다/하나만/없음 자동 처리.
- **카운터**: "N / N 카드" → "총 N 건(YouTube n건, WWW n건)"(검색·태그 필터 연동).

## 4. 카드 작성 규칙(현행)
프론트matter에 필요한 링크만 넣으면 됨:
```yaml
video: https://youtu.be/...   # 유튜브(없으면 생략)
link:  https://example.com/... # 웹페이지(없으면 생략)
source: C:/ai-bok/ref/KM/.../전문스크립트.txt  # 있으면 "스크립트 전문" 링크
```
- 신규 자료 원천: `C:/ai-bok/ref/KM` (일자별/주제별 폴더)
- 유튜브 자막: `C:/ai-dev/apps/yt-dlp/km-subs.cmd "<URL>" "<출력txt>"`
